# 长秋山后台管理 · 全局设计规范 v3

> 用于统一所有 B 端后台页面的侧边栏、顶部栏、设计稿宽度、滚动行为。
> 每个 narrow-fix prompt 都必须明确引用本规范,严禁脱离规范自行发挥。

## 一、画布尺寸(强制)

- 设计稿宽度 **1440px**(不是 1280,不是 1920,不是 1707)
- 设计稿高度 **900px** 起,内容超出时整页可纵向滚动
- 所有内容(顶栏+侧边栏+主区)必须装在 1440px 宽度内,不允许换行/折断
- 内部区块(表格、卡片群、图表)宽度超容时显示横向滚动条而非换行

## 二、Topbar 顶栏(高 64px,白底 #FFFFFF,1px 底边 #EEE,内边距左右 24)

- **左侧**(从左到右,固定显示):
  1. 圆形 Logo 32px(主色 #2D5A27,白色山形剪影)
  2. 项目全称"长秋山森林公园智慧景区"(16/700 主色 #2D5A27)
- **中部**:面包屑(13 灰 #6B7280),格式 `首页 · <一级分组> · <当前页名>`,当前页主色
- **右侧**(从右到左):
  1. 用户头像 32 + "系统管理员"(13 #1F2937)+ 12 下拉箭头
  2. 1px 浅灰竖线 高 20
  3. 帮助图标 ?(20 灰)
  4. 通知铃铛(20 灰)+ 红色未读小角标"3"
  5. 全屏图标(20 灰)

> 严禁出现:Dashboard / Analysis / Help / Notifications / fullscreen / Search 等英文标签。
> 严禁出现:"概览 / 设置 / 资源"这类与全局菜单冲突的二级 tab。
> 严禁出现:"长秋山管理中心"、"管理中心"、"Evergreen Admin"、"Changqiu Forest"、"长秋管理"、"指挥中心" 等任何变体头衔。

顶部内边距 24,Logo 24 + "长秋山森林公园智慧景区"(14/600 #E8EFE3)+ 副标题"管理后台"(11 #A8C09A)

> 严禁出现侧边栏头衔变体,只能是"长秋山森林公园智慧景区"+ "管理后台"。

## 四、主内容区(left: 240, top: 64, 剩余空间 padding 24)

- 顶部面包屑条下方,首先是页面 H1(28/700 #1F2937)+ 一行描述(13 #6B7280)
- 接着是 KPI 卡片群 / 筛选条 / 表格或图表区
- 卡片群必须为等宽 4 列(KPI 用)或自适应 grid,不得换行到第二行
- 表格列超容时:整个表格容器横向滚动,表头随之滚动(不要让单行 cell 换行)
- 长文本字段(地址、备注、ID 长串)用 `text-overflow: ellipsis` 单行截断 + hover title 提示

## 五、严禁项总览(任何一项都视为不通过)

1. 任何英文菜单 / 标题 / 标签 / 占位符 / aria-label(白名单见 PRD)
2. 任何非 1440px 宽度的设计画布
3. 任何被换行折断的卡片群、KPI 行、tabs 行
4. 任何额外的"概览/设置/资源"页面级 tab(只允许全局面包屑)
5. 任何与第三节不一致的菜单项
6. ISO 格式日期 `2026-05-27`,必须 `2026 年 5 月 27 日`
7. 任何"门票/票价/购票/退款/票务"等 PRD 红线词
