## 优先级与方案

### R1 · 红线 domain 单测（唯一"高价值且该现在做"）
- 现状：全仓**零测试文件**，无测试 runner。纯函数 `app/src/modules/booking/domain/rules.ts`（`assertDualElements:15` / `isCircuitBroken:44` / `canResume:48` 等）易测、回归保险最廉价。
- 方案：装 **vitest**（轻、与 Vite/TS 友好，不与 Next webpack 冲突）。
  - `pnpm add -D vitest`；`package.json` 加 `"test": "vitest run"`、`"test:watch": "vitest"`。
  - 新建 `app/src/modules/booking/domain/rules.test.ts`：
    - `assertDualElements`：身份证校验位合法/非法、车牌(普通+新能源)合法/非法、`plate XOR noVehicleDeclared` 四象限（缺、双、仅车牌、仅声明）。
    - `isCircuitBroken`：89%/90%/91% 边界、capacity=0 防除零。
    - `canResume`：低于恢复阈值才 true、迟滞区间不抖动。
  - 同理可补 `riskcontrol`/`checkin` domain 纯函数（爽约计数阈值、`verifyRotatingCode` 时间窗、`isCurrentSlotValid`）。
- 验证：`pnpm test` 全绿；CI 串入 `pnpm lint && pnpm test`。
- 红线对照：双要素(#2)、90% 熔断(#4) 的纯函数级回归。

### R2 · 路由级 RBAC（纵深防御）
- 现状：`app/src/middleware.ts` 仅校 cookie 存在性 + issuer；**action 层已是强制点**（6 个 actions.ts + B08 内联均 `requireRole`）。
- 方案：middleware 解出 `app_metadata.role` 后按路由前缀粗粒度拦截（如 `/system/*`→SUPER_ONLY、`/analytics|/content|/riskcontrol`→ADMIN_UP），与 `infrastructure/auth/guard.ts:requireRole` 同一角色枚举，避免双源漂移。
- 注意：仅作纵深防御，**不替代** action 层强制点；middleware 在 edge，只用 `jose`（已在用）。
- 验证：未授权角色访问越权路由被 302/403；授权放行。

### R3 · a11y 走查
- `app/src/app/(admin)/system/_account-manager.tsx` 的 `window.prompt` → 内联受控表单（小程序无关，纯 Web a11y）。
- 表单控件补 `<label htmlFor>` 关联；`BarList` 等图表加 `aria-label`/等价数据表。
- 验证：键盘可达、读屏有意义；无 `window.prompt` 残留。

### R4 · X.2 设计系统英文黑名单断言
- 现状：`scripts/lint-cn.mjs` 已扫中文红线（门票/票价/ISO 等）。
- 方案：补一条断言测试或扩 lint-cn 词表，覆盖"孤立英文按钮/标题"黑名单（Profile/Settings/Logout/Sign up 等），纳入 `pnpm lint:cn`。
- 验证：植入违规样例能被拦。

### R5 · B12 高德路况地图（依赖外部 key，按需）
- 现状：`app/src/app/(admin)/traffic/road/page.tsx` 占位；高德 JS API 非 npm、需 key；停车 B13 已附等价数据表(a11y)。
- 方案：取得高德 key 后注入 JS API（`dynamic ssr:false` 客户端岛）；在 key 到位前保持占位 + 等价数据表。**阻塞于外部 key，非代码问题。**

### R6 · 审计日志补全（P2）
- `resetPassword`/`createAdmin` 等写操作补 `sys_audit_log`（操作人=auth UUID + 动作 + 目标），与现有审计写入同范式。
